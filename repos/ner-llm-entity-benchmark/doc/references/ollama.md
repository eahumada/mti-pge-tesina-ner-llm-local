# Ollama

**Full Name:** Ollama
**Category:** Tertiary
**Relationship to the Project:** Provides the essential local inference infrastructure. Ollama enables the deployment of open-source LLMs (Gemma, Llama, DeepSeek) on-premises, fulfilling the project's non-functional requirement for data sovereignty and zero-leakage.
**Link:** [https://ollama.com](https://ollama.com)
**Description:** A lightweight, local LLM serving engine that simplifies the process of running, managing, and interacting with large language models via a standardized API.
