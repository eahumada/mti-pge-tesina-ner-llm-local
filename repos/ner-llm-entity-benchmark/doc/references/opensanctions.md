# OpenSanctions

**Full Name:** OpenSanctions
**Category:** Tertiary
**Relationship to the Project:** Serves as a critical reference index and ground-truth source for the validation of extracted entities. It provides the structured mapping of sanctions and PEP lists used to verify model accuracy.
**Link:** [https://opensanctions.org](https://opensanctions.org)
**Description:** A comprehensive open-source database that aggregates, cleans, and indexes sanctions and Politically Exposed Persons (PEP) lists from diverse global authorities into a unified format.
