# Claude Instructions: Project Sources

When adding new sources to this directory:
1. Create a new `.md` file named after the source (e.g., `opensanctions.md`).
2. Include a summary of the source, its relevance to the project, and any specific constraints or data formats it introduces.
3. Link the source back to the relevant functional or non-functional requirements in `doc/REQUERIMENTS/`.
4. Update the main `doc/sources/README.md` index.
