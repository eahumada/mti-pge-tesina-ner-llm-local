# FollowTheMoney (FtM)
FollowTheMoney is an open-source tool for managing and analyzing data on people and companies.

**Relevance:** The system implements support for the FtM JSONL format in `src/data_loader.py` to ensure compatibility with standard compliance data pipelines.
**Relationship to Requirements:** Directly relates to the "Adaptive Dataset Loader" finding in `AGENTS.md`.
