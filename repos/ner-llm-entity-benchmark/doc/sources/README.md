# Project Sources and References

This directory contains the documentation and references for the data sources and tools used in the NER-LLM Entity Benchmark project.

## Index of Sources
- [OpenSanctions](opensanctions.md) - Primary source of sanctions data.
- [Kleptotrace](kleptotrace.md) - Dataset used for NER benchmarking.
- [FollowTheMoney (FtM)](followthemoney.md) - Data format and schema reference.
- [Ollama](ollama.md) - Local LLM serving engine.

## Purpose
These documents ensure that the data engineering and model selection process is transparent and reproducible for the academic thesis.
