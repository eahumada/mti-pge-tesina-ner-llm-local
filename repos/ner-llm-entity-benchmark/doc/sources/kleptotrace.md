# Kleptotrace/CoNLL-2002
Kleptotrace/CoNLL-2002 is a dataset focusing on financial crime and corruption tracking, often used to test NER capabilities on complex financial news.

**Relevance:** Used as a primary benchmark dataset (`data/benchmark_balanced_120.json`) to measure model performance across Person, Organization, and Location entities.
**Relationship to Requirements:** Essential for calculating F1-Score, Precision, and Recall metrics.
