# Research References (USM MTI Theses)

The following academic works from Universidade Federal de Santa Maria (UFSM) serve as research references for the development and validation of the NER-LLM-Entity-Benchmark project, providing context on Intelligent Agents and Software Engineering best practices.

## 1. Intelligent Agents & Context Awareness
- **Title:** ELAI: intelligent agent adaptive to the level of pre-expertise of students
- **URL:** [http://repositorio.ufsm.br/handle/1/15250](http://repositorio.ufsm.br/handle/1/15250)
- **Relevance:** Provides foundational knowledge on adaptive agent behavior and human-agent interaction, useful for the prototype's qualitative validation phase.

## 2. Search-Based Software Engineering (SBSE)
- **Title:** Análise de aplicabilidade de search-based software engineering em gerência de requisitos em projetos de software
- **URL:** [https://repositorio.ufsm.br/handle/1/22525](https://repositorio.ufsm.br/handle/1/22525)
- **Relevance:** Offers methodologies for applying heuristic search to requirements management, which can be applied to optimizing the entity extraction pipeline and prompt selection.
