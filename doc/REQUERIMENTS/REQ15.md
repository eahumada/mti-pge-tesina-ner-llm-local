# Requirement Details: NFR2.2

## Metadata
- **ID:** NFR2.2
- **Category:** Functional
- **Title:** Low Hallucination Tolerance
- **Source File:** non_functional_requirements_enriched.md
- **Enriched:** Yes

## Description
The system's prompt engineering and RAG architecture must minimize the hallucination rate to under 5%. In compliance, false positives (alerting on innocent parties) create high operational friction, while false negatives (missing risks) expose the business to massive regulatory fines.
