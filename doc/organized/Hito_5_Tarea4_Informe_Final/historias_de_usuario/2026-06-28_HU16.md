## Historia de Usuario
**As a Quality Assurance Engineer, I want to automatically verify the system performance against our target acceptance criteria (F1 >= 85%, Hallucinations < 5%) so that I can validate whether a release is production-ready.**

## Acceptance Criteria
- [x] A summary JSON output lists overall F1 and hallucination rates.
- [x] The dashboard tab highlights whether target F1-Score of 85% is met.
- [x] The dashboard tab flags warning notices if hallucination rate is above 5%.
