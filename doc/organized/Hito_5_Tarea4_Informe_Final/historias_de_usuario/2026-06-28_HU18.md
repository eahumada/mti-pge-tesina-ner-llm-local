## Historia de Usuario
**As a Product Owner, I want to run the best performing model in a simulated daily production batch and collect qualitative feedback from compliance stakeholders at LeanStack SpA so that I can validate the practical utility of the system for real-world operational use.**

## Acceptance Criteria
- [x] Simulate a realistic daily batch processing flow of news articles.
- [x] Present results to compliance stakeholders via the Streamlit dashboard.
- [x] Capture and document qualitative feedback on whether the extractions are "actionable" and reduce manual workload.
- [x] Validate that the end-to-end turnaround time (ingestion to extraction) meets the operational window (minutes vs. days).

## Implementation Details
Implemented via `src/main.py` (batch mode) and `src/dashboard.py` (feedback/review view).
