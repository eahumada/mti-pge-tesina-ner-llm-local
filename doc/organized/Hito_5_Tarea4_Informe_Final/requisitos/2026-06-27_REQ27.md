# Requirement Details: NFR4.1

## Metadata
- **ID:** NFR4.1
- **Category:** Functional
- **Title:** Pluggable LLM Architecture
- **Source File:** non_functional_requirements_enriched.md
- **Enriched:** Yes

## Description
The software must use abstract interfaces (such as LangChain wrappers) so that adding, removing, or updating underlying local LLMs requires only configuration changes rather than extensive code rewrites.
