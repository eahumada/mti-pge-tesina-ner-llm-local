# Requirement Details: NFR3.3

## Metadata
- **ID:** NFR3.3
- **Category:** Functional
- **Title:** Hardware Utilization
- **Source File:** non_functional_requirements_enriched.md
- **Enriched:** Yes

## Description
The system must efficiently manage GPU/CPU memory boundaries during inference to prevent Out-Of-Memory (OOM) crashes when cycling between multiple LLMs (e.g., unloading weights appropriately in Ollama).
