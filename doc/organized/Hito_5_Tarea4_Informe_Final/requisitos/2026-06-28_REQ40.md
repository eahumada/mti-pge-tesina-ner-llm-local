# Requirement REQ40: Fine-Grained Error Taxonomy

## Metadata
- **ID:** REQ40
- **Title:** Fine-Grained Error Taxonomy
- **Category:** Functional (Evaluation)

## Description
The evaluation pipeline must categorize entity extraction errors into fine-grained groups (Boundary Errors, Type Confusion, Abbreviation Misses, and Extrinsic Hallucinations) to provide deep qualitative failure analysis.
